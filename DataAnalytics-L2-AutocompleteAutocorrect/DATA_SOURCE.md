# Data Source

The Oasis Infobyte task sheet recommends Project Gutenberg books as a public-domain source for a large text corpus.

Recommended source:
Project Gutenberg — https://www.gutenberg.org/

Download one or more public-domain English books as plain text and combine them into:

`corpus.txt`

The notebook intentionally does not hard-code a specific book because the task permits different corpus selections.

The corpus should contain enough continuous English text to produce a meaningful vocabulary and n-gram frequency distribution.

Before running the notebook, place `corpus.txt` in the same directory as the notebook.

No benchmark results are pre-filled. All metrics and predictions are calculated from the corpus supplied by the user.
