# Dataset Source

Dataset: Credit Card Fraud Detection

The project follows the Oasis Infobyte task sheet recommendation of the benchmark credit-card fraud dataset containing 284,807 transactions and 492 fraudulent transactions.

The dataset is commonly distributed through Kaggle under the title:

**Credit Card Fraud Detection**

The dataset contains anonymized PCA-transformed variables `V1` through `V28`, together with `Time`, `Amount`, and the binary `Class` target.

Download the dataset from the Kaggle dataset referenced by the internship task sheet and place:

`creditcard.csv`

in the notebook directory before running.

The notebook does not embed the raw dataset because it is a large external dataset.

Dataset description:
- Rows: 284,807
- Fraudulent transactions: 492
- Target: `Class`
  - 0 = non-fraud
  - 1 = fraud

The task sheet identifies this dataset as a benchmark for fraud-detection modelling.
