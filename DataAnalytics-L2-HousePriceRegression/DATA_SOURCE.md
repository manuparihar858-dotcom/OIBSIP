# Dataset Source

Dataset: Ames Housing

The dataset is loaded through the OpenML repository using:

`fetch_openml(name="house_prices", as_frame=True, parser="auto")`

OpenML dataset name: `house_prices`

The dataset is associated with the Kaggle House Prices: Advanced Regression Techniques competition and contains residential property features with `SalePrice` as the target.

The raw dataset is not committed to this repository. It is retrieved when the notebook is executed.
